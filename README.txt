FileBox - build the APK
1. Create a GitHub repo, upload everything in this folder (keep .github/workflows/build.yml).
2. Open Actions tab -> "Build APK" runs automatically (or Run workflow).
3. When green, download artifact "FileBox-apk" -> unzip -> app-debug.apk -> install.
4. Open FileBox -> Give access (All files access) -> use C: tab.
